## Remaining engineering work

These are explicit limits rather than completed features:

1. **Research validity, high priority:** current exact checks are small and often fail at baseline (MAP-006 only 1/4). Add separate answer/format scoring and a modest frozen task suite before interpreting capability preservation. Existing character vocabulary misses even clear prompted style; never promote it to a persona score.
2. **Long-run lifecycle, high priority:** stop preserves recent JSON/tokens through process termination, not model KV/RNG state. Exact interrupted-trajectory continuation remains unavailable. Add cooperative cancellation and specify whether continuation is between trials or a true state checkpoint. CLI process discovery is a convenience guard, not an interprocess scheduler.
3. **Evidence validation, medium priority:** verifier coverage varies across legacy/report paths; source hashes and a saved schedule do not prove a schedule has the full intended product or that every output's semantics match inputs. Keep independently recomputed product/baseline checks where implemented; add equivalent checks before new generic runner/report reuse. runtime_identity is conservative across all platform lock entries and may reject a harmless graph expansion; do not weaken it to bypass backend drift.
4. **UI, medium priority:** no isolated browser tool was available. Visual layout, keyboard navigation, screen-reader behavior, zoom and narrow viewports remain unverified. DOM/API checks are useful but do not complete that QA. Historical raw/vector artifacts remain absent; no data was invented to fill those screens.
5. **Maintainability, medium priority:** several compact scripts repeat setup/schedule/emit/check patterns and use long multi-statement lines. Preserve archived historical code; extract shared lifecycle code when implementing the next runner, with meaningful parity tests. Avoid a broad rewrite of working research paths during migration.
6. **Performance, deferred:** no justified 128K Mac claim. Eighteen GiB is shared system memory, and short decode rates are not sustained long-context throughput. Run separately frozen gradual memory trials before any large study. No MLX/quantization conversion is needed for the verified path; a later backend change would require new evidence.

## Recommended execution order

First freeze the smaller higher-budget Mac Qwen protocol and extend the evaluator to read it, keeping QWN-002 protected. Then build a better LFM task baseline and test one narrower intervention-placement hypothesis with MPS calibration, prompting/random controls and fresh prompts. Privately transfer Windows raw artifacts only if historical raw review is desired. Complete visual QA when an isolated surface exists. Detailed budgets and stopping rules are in [NEXT-STEPS.md](NEXT-STEPS.md).

The lab can now run on the Mac while preserving its central distinction: changing tokens is an observation; a reliable trait or capability improvement requires fresh controlled evidence.
